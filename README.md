# ReactJS Study Notes

This repository is my personal set of ReactJS study notes. I record the ideas, examples, and questions I return to while learning and working with React. The goal is to keep the core concepts in one place, explain them in my own words, and connect each idea to code I can run and change.

## Scope

These notes focus on React with JavaScript. They cover components, JSX, props, state, events, forms, effects, context, reusable hooks, loading states, error handling, accessibility, and performance. Examples use small interfaces so I can see how data moves through a React application before combining the same ideas in a larger feature.

The current notes target React 19.3. React and its tools continue to change, so I check the linked official references when an API or recommended setup may have changed. TypeScript is outside this set of notes.

## How these notes are organized

The first 15 chapters cover the core concepts in a practical order. Each topic chapter includes explanations, JavaScript examples, review questions, and links to the previous and next chapter. Chapter 98 collects the code samples. Chapter 99 gathers the questions with their answers.

## Learning in practice

I use the examples as a starting point for small experiments. I change one part at a time, observe what React renders, and keep notes about the result. When an example depends on a browser API or a server, I call that out so the boundary is clear. I update these notes as my understanding improves.
